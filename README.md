# Marketing Self-Check

Check your own marketing before you publish it. This plugin adds one skill. It reads a landing page, email, ad, social post, offer or proposal you made, quotes any lines that use a known manipulative tactic such as fake urgency, false scarcity, fake testimonials or hidden fees, and works through Numu's public 7-question checklist. It gives no scores. It isn't a review, an audit, a certification or advice.

## How to use it

Ask Claude to check your copy, for example "Check this landing page for dodgy tactics", and paste the text itself. A description can't be checked line by line. The findings list the lines to change, what the text shows against the questions a reading can answer, and the two questions only you can answer.

## Your data

This plugin has no code and sends nothing to Numu. The text you check goes only to the AI app you run it in, such as Claude, and that app's privacy terms apply.
